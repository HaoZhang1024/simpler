# A6 percounter SWA 性能分析与每日进展

更新日期：2026-11-20。本页供黄区内网持续记录。首次将全文复制为一页；内网已有此页时，把新增的回填栏目追加到原页，保留已填记录。黄区填现场结果和内网文件位置，蓝区更新统计、结论和每日摘要。

**目标是缩小单卡 DSV4.1 SWA 在 A6 与 A5 上的时延差距。** 两侧使用 percounter 回放同一个 SWA 子层，同一份输入和参考输出。主指标为 L0 AICore wall，另跟踪 L0 Device 时延和数值校验。**当前第一项是完成 A6 CntNotify 实验。** 已有 SWA 整图基线，CntNotify 原始结果待回传。

## 基线与待解释的差距

| 指标（µs） | A6 | A5 | A6 多用 |
| --- | ---: | ---: | ---: |
| L0 AICore wall，正式轮均值 | 265.768 | 185.173 | 80.595 |
| L0 Device，正式轮均值 | 357.712 | 296.698 | 61.014 |
| L4 整图，从首个 kernel 开始到末个 kernel 结束 | 453.489 | 320.997 | 132.492 |

L0 各预热 1 轮、测 10 轮。A5 runtime 为 `26b0511f3`，A6 数据来自已通过输出校验的黄区现场移植版。整理后的 A6 源码为 `cf78bd31a`，其 L0 值待复测。L4 开启了详细打点，两侧各取 1 轮定位；A6 有 1 轮预热，A5 此次采集直接测首轮。优化收益用 L0 同卡复测确认。

两端各有 16 个计算任务。A5 每组有 1 个计算核（AIC）和 2 个向量核（AIV），本轮 L4 实际用到 32 AIC + 64 AIV，共 578 个执行实例。A6 每组有 1 AIC + 1 AIV，本轮用到 54 AIC + 54 AIV，适配后的任务图共 570 个执行实例。这个差异在三项任务上可以直接观察。

| 任务 | L4 已观测 | 下一步要回答的问题 |
| --- | --- | --- |
| t22，48 个 block 同步启动 | 最晚可见计算前驱结束到首 dispatch，A6 为 38.986 µs，A5 为 27.813 µs。任务自身的 kernel 跨度另多 14.290 µs | 在同一轮定位第 48 个 block 发出加一、首个核读到 48、首 dispatch。当前还缺前两个事件和无 kernel 前驱 t21 的完成时刻；11.173 µs 的启动差值中，计数等待占多少仍待测 |
| t25，64 个向量 block | A6 有 10 个向量核各执行两块，两块之间的间隔中位数为 13.916 µs。任务 kernel 跨度比 A5 多 23.182 µs | 在复用的核上拆开前块完成发布、取票、准备和下一块启动 |
| t35，64 个向量 block | A6 同样复用 10 个向量核，间隔中位数为 13.632 µs。任务 kernel 跨度比 A5 多 20.249 µs，且末块也是整图最后一个 kernel | 先看最后结束的 worker 69，再用 t25 的 worker 84 对照，判断哪段缩短后能让整图更早结束 |

## 测试方法与执行顺序

1. **先测 CntNotify 和 GM 的并发时延。** 黄区继续当前 probe。目标为 48 AIC + 48 AIV 并发访问同一 32-bit 地址，每核每轮一次，每个读、写组合各 192 个正式轮。对照普通 GM 读写、GM atomic、CntNotify SET/read；写组记录写后 DSB，原子组保留实际操作。回传已有的逐核起止 tick、轮次、核号与核型、计时频率、配置、映射与读回日志。作业中断时回传已生成的数据及 SDK 返回码。
2. **蓝区计算完成名次，再判断 t22 能用哪种操作。** 确认跨核时钟可比后，每轮以最早开始为零点，按结束时间排序；跨轮报告第 1、48、96 名的均值和 P10/P90。96 核始终并发。SET/read 给出同址读写时延；t22 需要 48 个 block 各加一。进入替换实验前，单独验证 INC 累加与读回阈值 48，并用同轮 L4 两个到达事件核对真实等待时间。
3. **回到 SWA 验证整图收益。** CntNotify 结果确认后，黄区在已分配的 A6 上用蓝区的 `tests/fdwic/a6_dsv41_scheduler/test_a6_swa.sh "$DEVICE"`（用 Bash 执行）复测固定版本。蓝区准备单项候选后，同卡、同输入、同一 plan、保持 570 个执行实例，关闭 L4，先重复基线 A/A 量波动，再按 A-B-B-A 跑基线与候选，每批预热 1 轮、正式 10 轮。保留逐轮值、AICore wall、Device 和输出校验。日报同时写“候选比同卡 A6 基线快多少”和“距 A5 仍差多少”，统一用 µs。
